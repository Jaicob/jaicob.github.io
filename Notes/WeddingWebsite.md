# Wedding Website      

A fully static wedding website I built for my wedding, using vanilla JS, Vite, GSAP animations, and Tailwind CSS v4. Features bilingual support (English/Korean), client-side password protection via SHA-256    
hashing, and an interactive "Our Story" page with canvas-generated watercolor mask effects.                                                                                                                                 
## AI Integration   

I built the entire site collaboratively with Claude Code. Beyond code generation, I set up a Discord MCP integration that allows my fiancée to request content updates — like guest list changes or copy edits — directly from a Discord channel without touching code. Claude processes her requests, makes the changes, and commits them automatically.
                   
## Stack  

Vite · Vanilla JS · GSAP · Tailwind CSS v4 · S3 static hosting
